# Baryum (v0.2 - Alpha)

Build en version alpha: Bugs présents et peut ne pas marcher/provoquer des crashs.  
Peut ne pas fonctionner sur toutes les calculatrices.  

Calculatrices testées:   
    
    - TI-83 Premium CE (Edition Python)  

Le module n'a pas été testé sur d'autres modèles.  

**Vous devez jailbreaker votre calculatrice avant d'utiliser Baryum, utilisez [arTIfiCE](https://yvantt.github.io/arTIfiCE/)**  


## Debug des problèmes connus (2 problèmes)  

Problème connus:  
    Après un lancement de programme, la calculatrice plante et redémarre. Baryum disparait de la liste [prgm].  

Résolution:  
    Deux cas:  
      Si vous avez toujours "AsmHook 2" dans la liste [apps]: relancez l'installation et Baryum remarchera.  
      Si vous n'avez pas "AsmHook 2" recommencez le jailbreak en utilisant bien la méthode affichée dans [arTIfiCE](https://yvantt.github.io/arTIfiCE/) et qui correspond à votre modèle de calculatrice  


Problème connu:   
    Les programmes ne se lancent pas  

_Aucune méthode de résolution n'a été trouvée, c'est un bug normal qui sera réglé dans de futur builds_. Restez attentifs au GitHub pour de nouveaux correctifs.
